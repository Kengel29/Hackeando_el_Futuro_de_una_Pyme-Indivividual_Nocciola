# Hackeando_el_Futuro_de_una_Pyme-Indivividual_Nocciola
Sitio web de Nocciola Coffee Bar &amp; Bakery (Santo Domingo, RD): menú 2025, sucursales, contacto, historia y asistente virtual “Nocci”. HTML, CSS y JavaScript.
Nocciola Digital

Sitio web de Nocciola Coffee Bar & Bakery, una cafetería y pastelería de Santo Domingo, República Dominicana, conocida por sus postres con Nutella. El proyecto cuenta la historia de su “resurrección digital” y reúne su información real en un sitio ligero, sin frameworks.

Páginas: Inicio · Menú · Historia del Misterio · Servicios · Contacto

Características:

Menú 2025 completo, con descarga en PDF
Datos reales de las sucursales de Naco, Bella Vista y Arroyo Hondo, con mapa
Modo oscuro que se mantiene en todas las páginas
Asistente virtual “Nocci” en formato de chat, que responde sobre precios, horarios y opciones sin gluten o veganas
Diseño adaptable a celular

Tecnologías: HTML5, CSS y JavaScript.

Cómo usarlo: descarga el proyecto y abre index.html en tu navegador.
